# Linux Automation Scripts

A collection of useful Linux automation scripts for servers, self-hosting, monitoring, and deployments.

## Includes

* Docker deployment helpers
* Backup scripts
* Cron automation
* System monitoring tools
* Log cleanup scripts
* Network utilities

## Purpose

These scripts are intended to simplify infrastructure management and improve automation workflows for small deployments and personal labs.
